# gamedata/

Put your own copy of the original 1992 CD version's `DUNE.DAT` and
`DNCDPRG.EXE` here.
Everything in this folder except this README is ignored by Git and must
never be committed.

Both are on the root of the CD (`DUNE.DAT` is about 398 MB). Mentat is made
for the CD version 3.7; other versions may follow. It reads rules and tables
from `DNCDPRG.EXE` but never runs it. File names are matched without regard
to case, and other files are ignored.

Tests that need the original files skip when they are not here.
