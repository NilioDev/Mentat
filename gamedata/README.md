# gamedata/

Put your own copy of the original 1992 CD version's `DUNE.DAT` here.
Everything in this folder except this README is ignored by Git and must
never be committed.

`DUNE.DAT` is on the root of the CD (about 398 MB). Melange is made for the
English CD version 3.7; other versions may follow. The file name is matched
without regard to case, and other files are ignored.

Tests that need the original files skip when they are not here.
